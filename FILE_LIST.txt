DEPLOYMENT STEPS
================================================================================

1. Import database:
   mysql -u root -p < health_monitoring.sql

2. Edit config:
   public/config/Database.php

3. Point web server to:
   public/ folder

4. Access system:
   http://localhost/login.php

5. Login:
   admin / admin123
