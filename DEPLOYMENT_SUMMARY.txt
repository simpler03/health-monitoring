HOW TO USE THIS DEPLOYMENT PACKAGE
================================================================================

OPTION 1: Direct Deployment on Server
---------------------------------------
1. Copy the entire "health-monitoring-deploy" folder to your server
2. Import the database:
   mysql -u root -p < health_monitoring.sql
3. Edit public/config/Database.php with your credentials
4. Point your web server's Document Root to the "public/" folder
5. Access: http://your-domain/login.php

OPTION 2: Create ZIP for Distribution
--------------------------------------
1. Right-click on "health-monitoring-deploy" folder
2. Select "Send to > Compressed (zipped) folder"
3. Name it: health-monitoring-v1.0.zip
4. Distribute the ZIP file

OPTION 3: Upload via FTP
-------------------------
1. Connect to your server via FTP
2. Upload the entire "health-monitoring-deploy" folder
3. Follow setup steps in QUICK_START.txt
