# Health Monitoring System - Deployment Checklist

## Pre-Deployment

### Server Requirements
- [ ] PHP 7.4+ installed
- [ ] MySQL 5.7+ or MariaDB 10.2+ installed
- [ ] Apache or Nginx web server configured
- [ ] PDO MySQL extension enabled in PHP
- [ ] At least 20MB free disk space

### Database Setup
- [ ] Create database: `health_monitoring`
- [ ] Import SQL file: `health_monitoring.sql`
  ```bash
  mysql -u root -p health_monitoring < health_monitoring.sql
  ```
- [ ] Verify tables created (should be 8 tables)
- [ ] Verify sample data loaded

### Configuration
- [ ] Edit `public/config/Database.php`
  - Set `$host` (usually 'localhost')
  - Set `$db_name` (usually 'health_monitoring')
  - Set `$username` (usually 'root')
  - Set `$password` (your MySQL password)

### Web Server Configuration

#### Apache
- [ ] Document Root points to `public/` folder
- [ ] `.htaccess` file is present and readable
- [ ] mod_rewrite is enabled
- [ ] AllowOverride All is set in Apache config

#### Nginx
- [ ] Add location block:
  ```nginx
  location / {
      try_files $uri $uri/ /index.php?$query_string;
  }
  ```
- [ ] Document Root points to `public/` folder

### File Permissions
- [ ] Set permissions on Linux/Mac:
  ```bash
  chmod 755 public/
  chmod 755 public/api/
  chmod 755 public/config/
  ```
- [ ] Ensure web server can read all files
- [ ] Ensure web server can write to session directory

### Security (Production)
- [ ] Enable HTTPS (SSL certificate)
- [ ] Change default demo passwords
- [ ] Remove or disable `test.php` and `diagnose.php`
- [ ] Set `session.cookie_secure = 1` in Auth.php
- [ ] Configure proper session timeout
- [ ] Set up regular database backups
- [ ] Review and restrict file permissions

## Troubleshooting

### Database Connection Error
- Verify MySQL is running
- Check credentials in `public/config/Database.php`
- Test connection: `mysql -u username -p -h localhost health_monitoring`
- Check PHP error logs

### Login Fails
- Clear browser cookies/cache
- Verify users exist: `SELECT * FROM users;`
- Check if users are active: `is_active = 1`
- Review PHP error logs

### AJAX Not Working
- Open browser console (F12) and check for errors
- Verify `public/api/` files exist and are accessible
- Check file permissions
- Verify session is active

### Page Not Found (404)
- Check web server configuration
- Verify Document Root points to `public/`
- Ensure `.htaccess` exists (Apache)
- Check URL rewrite rules

### Scores Won't Save
- Check user has proper role (admin or input)
- Verify evaluation status is 'draft' (not completed)
- Check browser console for JavaScript errors
- Review PHP error logs
- Verify database connection
