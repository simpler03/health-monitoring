SETUP IN 3 SIMPLE STEPS
================================================================================

STEP 1: CREATE DATABASE (1 minute)
-----------------------------------
Option A - Command Line:
  mysql -u root -p < health_monitoring.sql

Option B - phpMyAdmin:
  1. Open phpMyAdmin
  2. Click "Import" tab
  3. Choose file: health_monitoring.sql
  4. Click "Go"

This creates the database with 8 tables and sample data.


STEP 2: CONFIGURE DATABASE CONNECTION (30 seconds)
---------------------------------------------------
Edit file: public/config/Database.php

Change these lines (around line 8-11):

  private $host = 'localhost';        // Your MySQL host
  private $db_name = 'health_monitoring';  // Database name
  private $username = 'root';         // MySQL username
  private $password = '';             // MySQL password

Save the file.


STEP 3: ACCESS THE SYSTEM (10 seconds)
---------------------------------------
1. Start your web server (Apache/Nginx)
2. Point Document Root to the "public/" folder
3. Open browser: http://localhost/login.php

================================================================================
WEB SERVER CONFIGURATION
================================================================================

APACHE:
-------
The .htaccess file is already included and configured.

Just set your Document Root:
  DocumentRoot /path/to/health-monitoring-deploy/public

Make sure mod_rewrite is enabled:
  a2enmod rewrite

And AllowOverride is set to All in your Apache config.


NGINX:
------
Add this to your server block:

  root /path/to/health-monitoring-deploy/public;
  
  location / {
      try_files $uri $uri/ /index.php?$query_string;
  }


LOCAL TESTING (PHP Built-in Server):
-------------------------------------
  php -S localhost:8000 -t public/
  
Then open: http://localhost:8000

================================================================================
TROUBLESHOOTING
================================================================================

DATABASE CONNECTION ERROR:
  → Check MySQL is running
  → Verify credentials in public/config/Database.php
  → Test: mysql -u root -p health_monitoring

LOGIN FAILS:
  → Clear browser cookies
  → Verify users exist in database
  → Check is_active = 1 in users table

AJAX NOT WORKING:
  → Open browser console (F12)
  → Check for JavaScript errors
  → Verify public/api/ files exist

SCORES WON'T SAVE:
  → Check user role (must be admin or input)
  → Evaluation status must be 'draft'
  → Check browser console for errors

PAGE NOT FOUND (404):
  → Verify Document Root points to public/
  → Check .htaccess exists (Apache)
  → Review web server config
